# Straightfern 1.0 TEST
Native Java/Canvas Android 8+ Str8ts-style consecutive-run puzzle.

Fill white tiles with digits 1-4. No digit repeats anywhere in a row or column, even across black X tiles. Each uninterrupted horizontal and vertical white run must contain consecutive digits in any order. There is no 2x2 box rule. Gold digits are fixed; black tiles carry NO numeric clues in this variant. Tap white editable tiles to cycle 1,2,3,4,blank. Twelve unique 4x4 blocked layouts and clue boards have twelve distinct solutions.

Saved straight palette and fixed marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java sorted-run and whole-line set oracle exhaustively checks row/column-compatible completions on each board, plus 30000 mutated arrays per board, against production min/max runs and pairwise exclusions. Exactly one solution each. Fixed and blocked cells, bounds, solve, undo, replay and wrong-length checks pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.
